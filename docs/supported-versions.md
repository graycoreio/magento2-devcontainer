# Supported Versions

| Devcontainer | Magento Open Source | Mage-OS | Mage-OS Minimal |
| --- | --- | --- | --- |
| 4.x | [2.4.7](https://github.com/graycoreio/magento2-devcontainer/blob/main/compose/magento/2.4.7/docker-compose.yml), [2.4.8](https://github.com/graycoreio/magento2-devcontainer/blob/main/compose/magento/2.4.8/docker-compose.yml), [2.4.9](https://github.com/graycoreio/magento2-devcontainer/blob/main/compose/magento/2.4.9/docker-compose.yml) | [4.0.0](https://github.com/graycoreio/magento2-devcontainer/blob/main/compose/mage-os/4.0.0/docker-compose.yml) | [4.0.0](https://github.com/graycoreio/magento2-devcontainer/blob/main/compose/mage-os-minimal/4.0.0/docker-compose.yml) |
| [3.x](https://github.com/graycoreio/magento2-devcontainer/tree/v3.4.0/compose) | 2.4.6, 2.4.7, 2.4.8, 2.4.9 | 3.0.0 | 3.0.0 |
| [2.x](https://github.com/graycoreio/magento2-devcontainer/tree/v2.0.0/compose) | 2.4.6, 2.4.7, 2.4.8, 2.4.9 (beta) | | |
| [1.x](https://github.com/graycoreio/magento2-devcontainer/tree/v1.1.0/compose) | 2.4.6, 2.4.7, 2.4.8, 2.4.9 (beta) | | |

Patch releases (e.g. `2.4.7-p10`) use the stack of their base version. Mage-OS releases use the newest stack with the same major version.
